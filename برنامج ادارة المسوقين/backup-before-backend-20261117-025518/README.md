# نظام إدارة المسوقين - بصمة سوفت
إصدار أولي تجريبي محلي 0.1.0

## التشغيل
1. افتح PowerShell داخل هذا المجلد.
2. نفّذ: `node server.js`
3. افتح: http://localhost:4173

## الموجود في النسخة
- واجهة عربية RTL متجاوبة مع الوضعين النهاري والليلي.
- لوحة مؤشرات، قاعدة عملاء، بحث، تحذير تشابه الاسم/الهاتف، وتصدير CSV.
- تسجيل الزيارات مع طلب GPS عند ضغط المستخدم فقط.
- تسجيل مبيعات واحتساب عمولة تجريبية.
- عرض فريق المسوقين وتقارير أولية.

## حدود مهمة قبل التشغيل الحقيقي
هذه نسخة واجهة تجريبية؛ البيانات تحفظ في LocalStorage على المتصفح والجهاز نفسه فقط. لا توجد قاعدة بيانات مركزية، أو تسجيل دخول حقيقي، أو صلاحيات آمنة، أو حجوزات متزامنة، أو مزامنة دون إنترنت، أو سجل تدقيق غير قابل للتلاعب. لا تدخل بيانات عملاء حقيقية قبل ربط Backend موثوق وتطبيق المصادقة والصلاحيات وسياسات النسخ الاحتياطي.
